Kebijakan Privasi

Nikahku berkomitmen penuh melindungi kerahasiaan data pribadi, kesehatan, dan keluarga calon pengantin sesuai prinsip Undang-Undang Perlindungan Data Pribadi (UU PDP).

1. Pengumpulan Data

Data yang Anda masukkan (biodata ta'aruf, riwayat kesehatan, catatan keluarga, anggaran, daftar tamu, dan pindaian berkas KUA) disimpan secara privat di dalam ruang data (workspace) akun Anda sendiri.

2. Tanpa Analitik Pihak Ketiga & Tanpa Penjualan Data

Aplikasi Nikahku tidak menggunakan pelacak pihak ketiga (seperti Google Analytics atau Facebook Pixel) dan tidak pernah memperjualbelikan atau membagikan data Anda kepada pihak pengiklan atau vendor manapun.

3. Penyimpanan & Keamanan Berkas

Semua berkas foto dan dokumen tersimpan di luar folder publik server web dan hanya dapat diakses melalui verifikasi sesi login yang sah. Terdapat fitur Blur Privasi pada data kesehatan dan keluarga untuk mencegah intipan visual di tempat umum.

4. Hak Pengguna & Penghapusan Data Permanen

Sesuai UU PDP, Anda memiliki hak penuh untuk:

  • Mengekspor seluruh data dalam bentuk file arsip ZIP/JSON kapan saja.
  • Memulihkan data dari cadangan mandiri.
  • Menghapus akun beserta seluruh data secara permanen dari server melalui menu Pengaturan Profil.
